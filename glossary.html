모델을 구성하고 실행하는 기초

입력에 2를 곱하고 1을 더하는 y=x×2+1을 작은 예로 사용한다. 예를 들어 x=4이면 y=9다.

용어 작은 예 뜻과 주의할 점
모델, model 입력에 2를 곱하고 1을 더함 입력으로 답을 만드는 계산 방법과 그 계산에 사용하는 숫자들이다.
가중치, weight 입력에 곱하는 수 2 입력의 각 값이 계산에 얼마나 반영될지 정하는 수다. 학습에서 조정할 수 있다.
바이어스, bias 곱한 뒤 더하는 수 1 입력에 곱한 결과를 더하거나 빼서 보정하는 값이다. 입력과 곱하는 가중치와 역할을 구분한다.
매개변수, parameter 가중치 2와 바이어스 1 모델이 보관하고 학습으로 조정할 수 있는 값들이다. 이번 호출에서 새로 넣는 입력 x와 구분한다.
추론, inference x=4를 넣어 답 9를 구함 이미 정한 모델을 새 입력에 사용해 답을 계산하는 일이다.
학습, training 예제의 정답에 맞도록 곱할 수·더할 수를 찾음 모델이 내는 답과 정답을 비교하며 가중치·바이어스 같은 값을 조정하는 과정이다.
커널, kernel 곱셈과 덧셈을 함께 처리하는 장치 함수 장치에 맡겨 실행하는 계산 함수다. 모델의 계산을 한 커널로 묶거나 여러 커널로 나눌 수 있다.
ReLU max(0, −1)=0, max(0, 5)=5 Rectified Linear Unit. 음수는 0으로, 0 이상은 그대로 두는 함수다. 배열에서는 각 원소에 적용한다.
체크포인트, checkpoint 저장한 가중치와 학습 상태 등 다시 읽어 모델을 구성하거나 학습을 이어갈 때 쓰는 저장물이다. 포함 항목은 형식에 따라 다르며, 가중치 파일을 곧바로 NPU 실행 바이너리로 보지 않는다.

숫자·배열·행렬의 기초

작은 배열의 값이 실제로 바뀌는 과정은 01·02장에서 이어 볼 수 있다.

용어 작은 예 뜻과 주의할 점 관련 장
스칼라·벡터·행렬 3, [1,2,3], [[1,2,3],[4,5,6]] 값 하나, 한 축을 가진 배열, 두 축을 가진 배열이다. 이 책에서 tensor는 이 배열 개념을 여러 축으로 넓힌 표현이다. 01 계산 기초
축과 인덱스 A[m,k] 축은 좌표를 바꾸는 방향이고 인덱스는 그 방향의 위치다. 행렬에서 m은 행, k는 열을 고른다. 01
내적 [1,2,3]·[1,0,1]=4 같은 위치끼리 곱한 뒤 모두 더한다. 길이가 같은 두 벡터에서 값 하나가 나온다. 01, 04
행렬곱 (2,3) @ (3,2) → (2,2) 왼쪽의 각 행과 오른쪽의 각 열을 내적해 출력 한 칸씩 만든다. 가운데 길이 3이 같아야 한다. 01
원소별 곱 [1,2,3]*[1,0,1]=[1,0,3] 같은 위치끼리 곱하며 자동으로 합산하지 않는다. 행렬곱과 구별한다. 01
Σ와 합산 1+0+3=4 여러 항을 더한다는 표기다. 반복문에서 total += term을 수행하는 것과 연결해 읽는다. 01
einsum "mk,kn->mn" Einstein summation 표기로 배열 계산을 적는 NumPy 함수다. 이 표기에서는 m·n을 출력에 남기고 k를 곱한 뒤 합산한다. 01
reshape (6,) → (2,3) 총 원소 수를 유지하며 축 길이를 바꾼다. 축 순서를 바꾸는 전치와 다르고, 항상 복사 없이 가능한 것도 아니다. 02
전치, transpose A.T 축의 역할을 교환한다. 행렬에서 A[m,k]가 전치 결과의 [k,m]에 해당한다. 02
layout, 메모리 배치 행부터 저장 / 열부터 저장 논리적인 배열의 값이 실제 메모리 위치에 대응하는 방식이다. 같은 shape라도 배치는 다를 수 있다. 01, 02
view x.T가 x와 저장 공간 공유 같은 저장 공간을 다른 모양·stride로 해석하는 배열이다. 한쪽 변경이 다른 쪽에 보일 수 있다. 02
contiguous, 연속 배치 C 순서에서 열 방향이 연속 지정한 순서로 원소를 차례로 읽을 수 있는 배치다. 전치된 값들을 C 순서로 만들면 복사가 필요할 수 있다. 02
broadcasting (2,3)+(3,) → (2,3) 작은 배열을 여러 위치에 반복 적용하는 모양 규칙이다. 모든 원소를 물리적으로 복제해야 한다는 뜻은 아니다. 02
타일, tile 큰 행렬을 작은 블록으로 나눔 한 번에 메모리에 두거나 계산할 작업 단위다. 타일 사이에 값을 재사용하거나 다음 타일 복사를 겹칠 수 있다. 02, 07
부분합 K의 앞부분 결과 1 + 뒷부분 결과 3 같은 출력 한 칸을 여러 작업이 나눠 계산했을 때 얻는 중간 합이다. 마지막에 합쳐야 전체 답 4가 된다. 01, 15

계산 표기와 배열 동작은 NumPy einsum, matmul, reshape, 배열·stride, broadcasting를 근거로 한다.

장치와 메모리

용어 풀네임 또는 공식 표기 쉽게 읽는 의미 관련 장
NPU Neural Processing Unit 신경망 계산을 실행하는 가속기. 이 책의 대상 장치는 FuriosaAI의 RNGD다. 1장 하드웨어
RNGD RNGD, 제품명 RENEGADE FuriosaAI의 2세대 NPU 제품. 카드·칩·PE를 같은 단위로 세지 않는다. 1장 하드웨어
TCP Tensor Contraction Processor 많은 배열의 곱셈·합산을 처리하는 Furiosa의 프로세서 구조다. CPU 프로그램 전체가 이 하드웨어 안으로 들어간다는 뜻은 아니다. 1장 하드웨어
PE Processing Element RNGD 안에서 계산·메모리 자원을 묶은 처리 단위다. 한 RNGD에는 8개가 있다. 사용하는 PE 수와 카드 수는 구분한다. 1장 하드웨어, 15장 여러 NPU
Cluster Cluster PE들을 묶는 칩 내부의 공간 계층. vISA에서 어떤 축을 어느 자원에 펼칠지 설명할 때 등장한다. 1장 하드웨어, 8장 vISA
Slice Slice PE 내부의 더 작은 공간 단위. 텐서 배치가 slice에 분산되는 방식은 메모리 접근과 계산 병렬성에 영향을 준다. 1장 하드웨어
Lane Lane slice 내부의 세부 데이터·연산 배치 단위. Python 텐서의 축 이름과 자동으로 일치하는 것은 아니다. 1장 하드웨어, 8장 vISA
HBM High Bandwidth Memory 장치가 사용하는 큰 고대역폭 메모리. 가중치·입력·중간값·KV cache가 용량과 대역폭을 함께 사용한다. 2장 메모리와 DMA
SRAM Static Random Access Memory RNGD 칩 안의 빠른 메모리를 설명할 때 쓰는 메모리 기술명. HBM보다 용량이 작아 재사용·배치가 중요하다. 1장 하드웨어, 2장 메모리와 DMA
DM Data Memory 장치 안에서 이번에 계산할 값들을 준비하는 데이터 메모리다. 큰 배열을 보관하는 HBM에서 필요한 부분을 옮겨 사용할 수 있다. 2장 메모리와 DMA
SPM Scratchpad Memory 인덱스 목록 같은 보조 데이터를 명시적으로 놓는 장치 메모리다. CPU의 자동 캐시처럼 알아서 모든 값을 보관하는 공간으로 보지 않는다. 2장 메모리와 DMA
TRF Tensor Register File 텐서 계산 가까이에 값을 잠시 보관하고 재사용하는 하드웨어 레지스터 저장소. 여기서 file은 디스크 파일이 아니라 레지스터의 묶음이다. 용량·배치 제약이 타일과 스케줄 선택에 연결된다. 1장 연산 파이프라인, 8장 vISA
VRF Vector Register File 벡터 연산에서 값을 보관하는 하드웨어 레지스터 저장소. TRF와 별도의 역할·접근 경로를 가지며 저장 장치의 파일이 아니다. 1장 연산 파이프라인
DMA Direct Memory Access 배열을 한 메모리에서 다른 메모리로 옮기는 일을 전송 엔진에 맡기는 방식이다. 요청한 뒤 언제 복사가 끝나는지는 여전히 확인해야 한다. 2장 메모리와 DMA
PDMA PCIe DMA host와 장치 HBM 사이를 PCIe로 이동하는 DMA 경로. 전송을 시작했다는 사실과 완료했다는 사실이 다르다. 2장 메모리와 DMA
TDMA Tensor DMA 장치 내부 텐서 이동에 사용하는 DMA 경로. 복사와 함께 배치·변환을 생각해야 한다. 2장 메모리와 DMA
PCIe Peripheral Component Interconnect Express host와 가속기 등을 연결하는 인터페이스. HBM 내부 대역폭과 host↔NPU 전송 대역폭은 다른 수치다. 1장 하드웨어, 2장 메모리와 DMA
NUMA Non-Uniform Memory Access host CPU와 메모리의 위치에 따라 접근 비용이 달라지는 구조. 장치에 가까운 CPU·메모리 배치가 전송 성능에 영향을 줄 수 있다. 2장 메모리와 DMA, 15장 여러 NPU

RNGD의 구조는 공식 하드웨어 개요, 세부 공간 계층과 메모리 이름은 vISA 공간·시간 축, 메모리 공간, DMA 문서를 기준으로 한다.

버퍼 Buffer 데이터를 담기 위해 확보한 메모리 영역이다. 전송이나 계산이 아직 읽는 동안에는 덮어쓰면 안 된다. 2장 메모리
메타데이터 Metadata 실제 값이나 코드와 함께 보관하는 설명 정보다. 배열의 크기·자료형, 파일의 구성·버전 등이 해당한다. 12장 패키지
MMIO Memory-Mapped Input/Output 장치의 제어 영역을 주소 공간에 매핑해 접근하는 방식. 일반 tensor 데이터 복사와 같은 것으로 보지 않는다. 3장 소프트웨어 계층
