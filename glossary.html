처음 만나는 용어

모든 단어를 번역하지 않습니다. 검색할 때 공식 문서와 코드에서 그대로 만나는 이름은 영어로 남겼습니다.

ATen
PyTorch의 tensor operator/dispatcher 층. FuryNo5에서는 lowering의 출발점입니다.
TCL
Furiosa tensor program/kernel을 표현하는 상위 개발 층. release별 API를 확인해야 합니다.
vISA
Virtual ISA. TCP와 low-level scheduling을 이해하는 instruction-level 표현입니다.
eISA
이 학습서에서 사용자가 말한 “확장 instruction 층”을 가리키는 편의 용어입니다. 공개 자료의 명칭은 주로 vISA입니다.
FXB
Furiosa 공식 compiler artifact/package 경로. Furiosa-LLM이 로드하는 모델 실행 자산입니다.
fxbx
FuryNo5/사용자 custom 실행·실험 경로에서 쓰는 확장 artifact 예시입니다. 공식 FXB와 같은 보증을 뜻하지 않습니다.
EDF
컴파일된 실행 계획·descriptor를 가리키는 문맥의 파일/계약 이름입니다.
RNGD
Furiosa NPU hardware family. 이 책에서는 장치·runtime·kernel 문맥으로 등장합니다.
KV Cache
LLM decode에서 이전 token의 key/value를 재사용하는 메모리. 용량과 bandwidth에 직접 영향을 줍니다.
TTFT / TPOT
Time To First Token / Time Per Output Token. serving latency를 나누어 보는 대표 지표입니다.
DMA
Host와 NPU memory 사이의 직접 데이터 이동. 작은 tensor 왕복이 병목이 되기 쉽습니다.
Driver
OS와 NPU device/runtime 사이를 연결하는 소프트웨어. SDK와 호환되는 버전을 맞춰야 합니다.
