# FuryNo5 개발자 학습서

FuryNo5와 Furiosa NPU 소프트웨어 스택을 처음 연결해 보는 사람을 위한 **비공식·학습서형 정적 사이트**입니다. 공식 문서의 번역본이 아니며, 설치된 SDK release의 API와 명령을 우선합니다.

사이트: https://smallstep-zzz.github.io/furyno5-handbook/

주요 범위: ATen → TCL → compiler/EDF, vISA(TCP) 개념, 공식 FXB와 custom fxbx 비교, Furiosa-LLM/vLLM, furiosa-smi 및 benchmark 방법.
