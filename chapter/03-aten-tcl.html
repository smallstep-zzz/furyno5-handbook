Chapter 03

ATen에서 TCL로 내려가기

ATen은 PyTorch가 이해하는 operator 이름과 의미의 층입니다. TCL은 그 의미를 NPU가 실행할 tensor region으로 구체화하는 층이라고 생각하면 쉽습니다.

작은 graph를 먼저 보자

import torch
def model(x, w):
    return torch.relu(x @ w)
gm = torch.fx.symbolic_trace(model)
print(gm.graph)

이 graph에서 aten.mm와 aten.relu가 보인다면, 각각에 대한 lowering rule 또는 decomposition이 있는지 확인합니다. FuryNo5는 이런 후보를 계획하고, 실제 compile·NPU 검증은 SDK에 위임합니다.

Unsupported operator의 정직한 처리

Unsupported는 “느리다”가 아니라 “계약이 없다”는 뜻입니다CPU fallback이 몰래 섞이면 숫자는 나오지만 NPU 성능과 재현성을 잃습니다. 연구 단계에서는 fallback="error"처럼 실패를 표면화하는 편이 안전합니다.
  1. 실패한 모델을 한 operator짜리 최소 예제로 줄입니다.
  2. 입력 dtype, rank, layout, shape를 기록합니다.
  3. 지원되는 primitive 조합으로 decomposition할 수 있는지 확인합니다.
  4. 새 TCL region을 만들고 CPU reference와 오차를 비교합니다.
  5. 작은 입력에서 NPU 실행을 확인한 후 전체 모델에 연결합니다.
# FuryNo5 연구 API의 개념 예시
from tclmachine import optimize
plan = optimize(model, example_inputs=(x, w),
                target="furiosa:0", fallback="error")
print(plan.unsupported)
용어 구분ATen operator를 직접 “vISA 명령으로 번역”하는 것이 아닙니다. 보통은 graph capture → TCL region/decomposition → compiler schedule → EDF/FXB라는 여러 단계를 거칩니다.
