Chapter 03

ATen에서 TCL로 내려가기

ATen은 PyTorch가 제공하는 텐서 연산의 집합입니다. NPU로 옮길 때는 원래 결과를 유지하면서, 하나 이상의 연산을 TCL로 표현해 컴파일할 수 있는지 확인합니다.

간단한 PyTorch 그래프 읽기

import torch
def model(x, w):
    return torch.relu(x @ w)
gm = torch.fx.symbolic_trace(model)
print(gm.graph)

이 예제의 FX 그래프에는 행렬 곱셈과 torch.relu 호출이 나타납니다. ATen 수준의 그래프를 분석할 때는 실제 기록된 ATen 연산 이름과 입력 조건을 확인하세요.

지원되지 않는 연산 조사하기

실패한 입력 조건을 기록하세요같은 연산도 데이터 타입이나 입력 크기에 따라 지원 여부가 달라질 수 있습니다. 실행이 성공했다면 문제의 연산이 NPU에서 실행됐는지, CPU로 넘어갔는지 확인하세요.
  1. 실패한 모델을 한 operator짜리 최소 예제로 줄입니다.
  2. 입력 dtype, rank, layout, shape를 기록합니다.
  3. 지원되는 primitive 조합으로 decomposition할 수 있는지 확인합니다.
  4. 새 TCL region을 만들고 CPU reference와 오차를 비교합니다.
  5. 작은 입력에서 NPU 실행을 확인한 후 전체 모델에 연결합니다.
용어 구분ATen operator를 직접 “vISA 명령으로 번역”하는 것이 아닙니다. 보통은 graph capture → TCL region/decomposition → compiler schedule → EDF/FXB라는 여러 단계를 거칩니다.
