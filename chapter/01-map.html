PyTorch 모델은 NPU에서 어떻게 실행될까?

먼저 이름을 외우지 말고, 데이터가 흐르는 방향을 보세요. 문제를 만났을 때 어느 층을 확인해야 하는지가 핵심입니다.

위 그림은 준비부터 실행까지의 공통 개념입니다. 공식 FXB, FuryNo5의 SDK Runnable 직접 실행, fxbX의 패키지 실행은 경로 비교에서 각각 살펴봅니다.

단계별로 확인할 것

층질문대표 증상
ATen / FXPyTorch graph에 어떤 operator가 남았나?trace 실패, dynamic shape
TCLregion을 tensor program으로 표현했나?NO_TCL_RULE
Compiler / EDFlayout·dtype·schedule이 제약을 지키나?compile rejection
Runtimeartifact를 올리고 queue에 제출했나?load 실패, host sync
NPU계산보다 이동이 더 오래 걸리나?낮은 utilization
FuryNo5가 하는 일FuryNo5는 어떤 PyTorch 연산을 TCL로 구현할지 검토하고, Furiosa SDK로 컴파일한 코드의 성능을 실제 NPU에서 측정하는 데 쓰입니다.
